## 4. نموذج الصفحة

### صفحة المسودة المحكومة

- هوية الموقع الحاكمة.
- شارة **مسودة خاضعة للتدقيق**.
- فقرة أو أكثر من السجلات التحريرية الـ92.
- إحالات واضحة إلى المصادر.
- تمييز التقليد الديني والتقرير المنسوب وعدم اليقين.
- حجب الادعاءات المعلقة.
- تعطيل الخريطة عند غياب إحداثية معتمدة.
- بديل بصري محايد عند غياب أصل مرخص.

### صفحة البحث المحدودة

- الاسم والهوية والمحافظة والتجمع.
- نوع السجل وحالة البحث.
- فجوات التوثيق.
- العلاقات والمكونات المعروفة.
- دعوة لتقديم مصدر أو وسائط.
- لا رواية تاريخية غير متحققة.
