# معايير القبول

## قبول المرحلة صفر

- وجود مرجع حاكم شامل.
- وجود ميثاق.
- وجود منهجية رواية ومصادر.
- وجود نموذج بيانات مفاهيمي.
- وجود حالات سير عمل.
- وجود RBAC مرجعي.
- وجود معايير نشر.
- وجود معمارية تقنية.
- وجود سجل قرارات وتغييرات وأخطاء.
- وجود Baseline مضغوط.
- عدم وجود تعديل كود أو قاعدة بيانات غير مصرح.

## قبول المرحلة الأولى لاحقاً

1. عرض المواقع حسب المحافظة والمدينة.
2. صفحة عامة لكل موقع.
3. وثيقة تاريخية متعددة الفصول.
4. تتبع الادعاء إلى المصدر.
5. خريطة وبحث متجاوبان.
6. لا كتابة عامة مباشرة.
7. المساهمات تمر بالمراجعة.
8. حقوق الملفات واضحة.
9. كل تعديل مسجل.
10. استعادة النسخ السابقة.
