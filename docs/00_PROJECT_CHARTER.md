# ميثاق مشروع بعيون فلسطينية

## الرسالة

حماية الذاكرة المكانية الفلسطينية وإتاحتها من خلال روايات تاريخية موثقة قابلة للتدقيق، تربط المكان بالمصدر والدليل والإنسان.

## المشكلة

المعلومات عن المواقع الفلسطينية موزعة بين كتب، أرشيفات، تقارير حفريات، خرائط، مواقع رسمية، صور عائلية، وذاكرة شفوية. كما تتعرض بعض المواقع للتحريف، أو الاختزال، أو التهديد المادي.

## القيمة المقترحة

- وثيقة تاريخية معمقة لكل موقع.
- تتبع كل ادعاء إلى مصدره.
- عرض مكاني وزمني.
- حفظ الذاكرة الشفوية.
- توثيق الحفظ والتهديدات.
- تمكين الباحث والمجتمع ضمن حوكمة واضحة.

## خارج النطاق في البداية

- النشر التلقائي بالذكاء الاصطناعي.
- التحرير العام المباشر.
- نسخ مصادر مقيدة الحقوق.
- إطلاق مئات الصفحات السطحية.
- كشف المواقع الحساسة.
- أي تعديل إنتاجي قبل التحقق والقبول.

## مقاييس النجاح

- نسبة الادعاءات المحورية المرتبطة بمصادر.
- اكتمال الوثيقة التاريخية.
- جودة ووضوح الحقوق.
- زمن المراجعة.
- تغطية المحافظات.
- عدد المواقع ذات تقييم حفظ حديث.
- القدرة على استعادة الإصدارات.
