# MEGA_BATCH_PAL_EYES_UI_UX_PRODUCTIVE_SURFACES_AND_GROUPED_NAVIGATION_V1

## الهدف

نقل المشروع من واجهة تأسيسية تعرض حالة Runtime إلى منتج مرئي قابل للاستخدام،
مع فصل واضح بين الموقع العام، مساحة العمل، وصفحات الحوكمة.

## المنجز

### Public Shell

- Header عام.
- تنقل أفقي للحاسوب.
- Drawer للهاتف.
- Bottom navigation للواجهات الضيقة.
- لا مساحة باحث أو إدارة في القائمة العامة.
- لا عبارات Runtime أو قاعدة البيانات في الصفحة العامة.

### Operational Workspace

Sidebar مبوب إلى:

1. الرئيسية والعمل اليومي.
2. المواقع والأماكن.
3. التوثيق والمعرفة.
4. الجغرافيا والاستكشاف.
5. المجتمع والمساهمات.
6. المراجعة والنشر والجودة.
7. الحوكمة والنظام.

### Draft content

أضيفت مسودات ظاهرة داخل صفحات:

- برك سليمان.
- سبسطية.
- تل السلطان.

وتشمل:

- ملخص الموقع.
- فصول الرواية.
- الادعاءات ومؤشرات الإحالة.
- مصادر أولية.
- خطاً زمنياً.
- وسائط وذاكرة شفوية.
- حالة الحفظ.

## الحدود

المسودات ليست منشورة ولا معتمدة. لم تُنشأ أي كتابة حية أو Migration.
