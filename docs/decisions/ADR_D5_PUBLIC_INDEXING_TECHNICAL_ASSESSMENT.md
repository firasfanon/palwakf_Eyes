# ADR D5 — تقييم تقني لفهرسة المحتوى العام (INDEXABLE_PUBLIC_CONTENT)

الحالة: **مقبول للتنفيذ في فرع المهمة** — `task/pal-eyes-integrated-product-development`
القرار السيادي المرجعي: `SEO_STRATEGY = INDEXABLE_PUBLIC_CONTENT`

## 1. المشكلة

تطبيق Flutter Web (CanvasKit) يرسم النص على Canvas؛ محركات البحث ترى ملف
`index.html` واحدًا لكل المسارات بعنوان ووصف ثابتين، ولا ترى نص الصفحات.
المطلوب: صفحات عامة قابلة للفهرسة، مع إبقاء Flutter لمساحة العمل والإدارة،
ودون منصتين عامتين منفصلتين ما لم تثبت الحاجة، ودون فهرسة أي محتوى غير منشور.

## 2. البدائل المقيّمة

| البديل | الفهرسة | الكلفة/التعقيد | خطر الازدواج | الحكم |
|---|---|---|---|---|
| A. Flutter فقط (الوضع الحالي) | ضعيفة: عنوان واحد، لا نص | صفر | لا | مرفوض — لا يحقق القرار |
| B. توليد HTML ساكن لكل مسار عام وقت البناء (Prerender shells) فوق نفس تطبيق Flutter | جيدة للعناوين/الأوصاف/canonical/JSON-LD/ملخص نصي حقيقي | منخفض؛ سكربت Python في CI | لا — نفس التطبيق يُقلع فوق كل صفحة | **مختار** |
| C. HTML renderer لـ Flutter | لم يعد مدعومًا في Flutter 3.44 (أُزيل) | — | — | غير متاح |
| D. SSR كامل بإطار ثانٍ (Next.js/Astro) يقرأ `public_sites_v1` | ممتازة | مرتفع: واجهة عامة ثانية، تصميم مزدوج، أمان وتشغيل مضاعف | **نعم — منصتان عامتان** | مؤجَّل: لا يُعتمد إلا إذا أثبتت قياسات الفهرسة بعد الإطلاق أن B غير كافٍ |
| E. Dynamic rendering (خادم يرسل HTML للزواحف فقط) | متوسطة | متوسط، وGoogle تعدّه حلًا مؤقتًا | جزئي | مرفوض |

## 3. القرار

**B: Build-time prerender** بأداتين:

- `tools/seo/public_routes.json` — مصدر واحد للمسارات العامة الثابتة (11 مسارًا) بعناوين وأوصاف عربية/إنجليزية، وقائمة `never_indexed_prefixes` (`/workspace`, `/admin`, `/sign-in`, `/access-restricted`).
- `tools/seo/generate_prerender.py` — ينسخ `index.html` المبني إلى `<route>/index.html` مع `<title>` ووصف وOpen Graph وJSON-LD و`canonical` و`hreflang` وملخص نصي حقيقي داخل `<noscript>`. صفحات المواقع (`/places/<slug>`) تُولَّد **فقط** من تصدير `public_sites_v1` (منشور فعلًا)، ويرفض السكربت أي صف ليس `PUBLISHED`.
- `tools/seo/verify_prerender.py` — يتحقق في CI: عنوان مميز لكل مسار، JSON-LD، نص الملخص، بقاء `flutter_bootstrap.js`، عدم توليد أي مسار داخلي، و`noindex` + `robots.txt: Disallow: /` وعدم وجود sitemap في غير الإنتاج.

قواعد البيئة:

- غير الإنتاج (local/staging): `noindex, nofollow` على كل الصفحات، `robots.txt` يمنع الكل، لا sitemap.
- الإنتاج: يتطلب `--site-url https://…` (مرتبط بقرار النطاق D7)؛ يولّد `sitemap.xml` من المسارات العامة والمحتوى المنشور فقط، و`robots.txt` يمنع `/workspace` و`/admin` و`/sign-in`.

## 4. حدود معروفة (صريحة)

1. نص الصفحة داخل Canvas لا يزال غير قابل للفهرسة؛ الفهرسة تعتمد على الرأس والملخص الساكن. هذا كافٍ للعناوين ونتائج البحث الأساسية وليس لفهرسة كامل السرد.
2. صفحات تفاصيل المواقع لا تُولَّد اليوم لأن عدد المواقع المنشورة = 0 (كل المحتوى مسودات محجوبة، القرار D8 معلّق).
3. التحقق الفعلي من الفهرسة (Search Console) يتطلب نطاقًا إنتاجيًا (D7) — **BLOCKED** حتى ذلك.

## 5. معيار إعادة النظر

يُعاد فتح البديل D إذا: (أ) نُشر ≥ 50 موقعًا وأظهرت Search Console أن الصفحات تُفهرس دون نص السرد بشكل يضر الوصول، أو (ب) طلبت الجهة السيادية فهرسة النص الكامل للسرد.
