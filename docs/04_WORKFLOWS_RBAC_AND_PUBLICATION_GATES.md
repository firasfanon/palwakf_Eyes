# سير العمل والصلاحيات وبوابات النشر

## الأدوار

| الدور | الوظيفة |
|---|---|
| super_admin | صلاحية شاملة |
| admin | إدارة تشغيلية |
| chief_editor | اعتماد المحتوى |
| historical_editor | تحرير الروايات |
| researcher | البحث والمصادر |
| fact_checker | تدقيق الادعاءات |
| geospatial_editor | الخرائط |
| media_editor | الوسائط |
| rights_reviewer | الحقوق |
| translator | الترجمة |
| trusted_contributor | مساهم موثوق |
| contributor | مساهم |
| viewer | قراءة |

## فصل الواجبات

- الباحث لا يعتمد بحثه منفرداً.
- المحرر لا يعتمد الحقوق منفرداً.
- مساهم المجتمع لا ينشر مباشرة.
- ناشر المحتوى يجب أن يملك صلاحية مستقلة.
- العمليات الحساسة تُسجل.

## بوابة النشر

```text
Identity Complete
AND Geometry Reviewed
AND Core Claims Sourced
AND Citations Verified
AND Rights Cleared
AND Language Reviewed
AND Sensitive Data Reviewed
AND Approval Decision Recorded
AND Version Snapshot Created
```

## الإرجاع للمراجعة

أي فشل يعيد المحتوى إلى الحالة المناسبة مع:

- سبب محدد.
- المراجع المسؤول.
- المهلة.
- عناصر التصحيح.
