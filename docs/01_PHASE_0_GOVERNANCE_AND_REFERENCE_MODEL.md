# المرحلة صفر: الحوكمة والنموذج المرجعي

## الهدف

تثبيت العقود التي تمنع إعادة تصميم المشروع أثناء التنفيذ، وتمنع خلط الرواية التاريخية بالمحتوى غير المتحقق.

## المخرجات الإلزامية

1. ميثاق المشروع.
2. منهجية الرواية التاريخية.
3. سياسة المصادر والحقوق.
4. نموذج البيانات المفاهيمي.
5. التصنيفات المرجعية.
6. حالات سير العمل.
7. مصفوفة الأدوار والصلاحيات.
8. معايير النشر.
9. متطلبات الأمن وRLS.
10. معايير القبول.
11. سجل القرارات والتغييرات والأخطاء.
12. Baseline مضغوط.

## الأعمال داخل المرحلة

### المسار A — اكتشاف المستودع

- تحديد مسار المشروع الفعلي.
- تحديد نقطة تشغيل Flutter.
- جرد بنية `lib/`.
- جرد GoRouter والمسارات الحالية.
- جرد Riverpod والإصدارات.
- جرد Supabase config والمخططات والجداول.
- جرد Storage buckets.
- جرد RLS/RPC/Edge Functions.
- جرد الملفات الحاكمة الحالية.
- تحديد أحدث baseline قابل للبناء.

### المسار B — العقود البحثية

- قالب الوثيقة التاريخية.
- نموذج الادعاء.
- نموذج الاقتباس والإحالة.
- نموذج المصدر.
- درجات الثقة.
- قواعد الخلاف التاريخي.
- موافقات الرواية الشفوية.
- حقوق الصور والوثائق.

### المسار C — العقود التقنية

- schema owner.
- public wrappers.
- RLS.
- RBAC.
- Audit.
- Versioning.
- Storage.
- Geospatial governance.
- Publication gates.

## بوابة الانتقال للمرحلة الأولى

لا يبدأ بناء الصفحات العامة قبل:

- اكتشاف المستودع الفعلي.
- تثبيت Route Contract.
- اعتماد نموذج البيانات.
- اعتماد RLS وRBAC.
- اعتماد مصدر الحقيقة للمحافظات والمدن.
- اعتماد قالب موقع تجريبي.
- اختيار 10–20 موقعاً Pilot.
